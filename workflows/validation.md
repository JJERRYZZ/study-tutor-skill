# Quality gate (perform before presenting a substantive result)
## Grounding
- Are slide counts, slide ranges and quoted definitions actually verified?
- Are diagrams, tables, equations and marked screenshot regions accounted for?
- Are course facts distinct from general explanations and uncertain inferences?
## Correctness
- Do formulas include definitions, assumptions and valid transformations?
- Are numerical examples internally consistent?
- Are quiz answers unique/valid, with correct option mapping and adequate question conditions?
## Completeness
- For full lecture mode, does every substantive page have an explained status in the ledger? If not, disclose remaining pages explicitly.
- For focused mode, did we answer the marked question before general background?
- For quick review, is it truly readable in 3–5 minutes?
- For cheatsheet, is the two-page physical constraint verified if a PDF was created?
## Teaching quality
- Does a key topic include the WHY/HOW and a useful example rather than a definition-only summary?
- Is Chinese clear and English terminology consistent with slides?
- Does the response match the requested mode and user skill level?
If any check fails, fix it or clearly disclose the limitation. Never claim a test passed without running it.
