# Quiz / exam review
1. Identify course, assessment, date and official scope from available materials. If not confirmed, proceed with available materials and label scope provisional.
2. Map every topic to source slides, tutorials, assignments and sample questions where verified.
3. Classify: **Confirmed by instructor**, **High review priority based on evidence**, **Possible extension / uncertain**. Never present probability as certainty.
4. For each core topic: knowledge point → importance/evidence → recognition keywords (especially English prompts) → common question type → misconception → worked question → solution procedure.
5. Integrate cross-week prerequisites and contrast frequently confused concepts.
6. For last-minute review, prioritize high-yield content without implying the rest is impossible to test.
7. Only cite teacher statements when actually supplied as lecture text/subtitles or official instructions.
