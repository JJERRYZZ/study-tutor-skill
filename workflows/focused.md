# Focused screenshot / formula / code explanation
1. Answer the exact question or marked region **first**. If several question marks, enumerate and answer each.
2. Transcribe only legible relevant symbols and labels. Identify axes, relationships, cardinalities, table columns, arrows and conditions as applicable.
3. Explain the question's purpose and the reasoning to the answer. For MCQ: state answer first, then brief explanation, and explain decisive distractors if useful.
4. For calculations: list assumptions and symbol definitions, show steps, verify arithmetic when possible. For diagrams: explain the actual visible structure rather than a generic textbook diagram.
5. If uncertain, identify the unreadable or missing element, give conditional alternatives, and request a clearer crop only if essential.
6. If user still doesn't understand, switch teaching strategy to a simpler example rather than repeating the same phrasing.
